## Prompts efectivos para resumir con IA

```
Resume este texto en 5 viñetas con los puntos más importantes.
Mantén cifras y fechas exactas. Responde en español.
```

```
Actúa como analista senior. Lee este informe y genera:
1) Resumen ejecutivo (100 palabras)
2) 3 riesgos identificados
3) 3 oportunidades
```

Cuanto más específico sea tu prompt, mejor el resultado.

## Conclusión

Para **PDFs y documentos largos gratis**, empieza con **NotebookLM**. Para **máxima precisión en textos extensos**, usa **Claude Pro**. Para **párrafos sueltos y emails**, **QuillBot** es rápido y barato. Y para **papers científicos**, **Scholarcy** ahorra horas de lectura.
